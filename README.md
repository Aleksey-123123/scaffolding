## Короткий вывод

**Не подписывать в текущем виде.**

1. **Не определено, что такое «м²».** Приложение 1 даёт 60 000 м² по 550 руб. Приложение 2
   описывает секцию 8 × 4 × 36 м, но не говорит, как считается площадь. Разница между
   «фасадная проекция» и «все вертикальные поверхности» — **3 раза** по эффективной ставке
   (550 против 1 650 руб/м² фасада). Это главный вопрос, всё остальное — вторично.
2. **Сетки нет в предмете договора.** Приложение 2: «Леса устанавливаются без сетки».
   Натяжение сетки — это +33 % трудозатрат, которые сейчас не оплачиваются ничем.
3. **Демонтажа в договоре нет** — ни в предмете, ни в расценке. Это ещё ~55 % от монтажа.
4. **Приложение 1 требует расчёта наличными** при 33 млн руб — прямое нарушение
   Указания ЦБ РФ № 5348-У (лимит 100 000 руб) и противоречие п. 2.5 (безнал).
5. **Объём не гарантирован** (п. 2.1), срока окончания работ нет (п. 3.1),
   погода — форс-мажор без оплаты простоя (п. 3.3).

При трактовке «м² = фасадная проекция» ставка 550 руб/м² **ниже себестоимости в 1,5–2,4 раза.**
